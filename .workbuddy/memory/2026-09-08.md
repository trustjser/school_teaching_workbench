## UI 全面重设计（现代感 + 交互动画 + 深色/浅色/高对比 + 主题切换）

**背景**：项目此前 Tailwind 开 `darkMode:'class'`、store 有 `theme`/`setTheme`（支持 light/dark/high-contrast），但主题从未落到 DOM、无深色样式，组件大量写死 `bg-white`/`slate-*`，实际只有浅色。

**做法**
1. 主题令牌系统：`src/theme.css` 用 CSS 变量定义三套主题（surface/ink/brand/glass 系列）；`tailwind.config.js` 的 `surface.*`/`ink.*` 映射到 `rgb(var(--x)/<alpha-value>)`；新增现代阴影（shadow-soft/glow）、`bg-brand-gradient`、一组动画 keyframes。
2. 主题落地：`src/lib/theme.ts`（applyThemeClass + localStorage 持久化）+ `main.tsx` 首帧前应用并订阅 store.theme；切换挂 `.theme-anim` 平滑过渡。Settings 页主题改用 `ThemeSwitcher` 动画分段控件。
3. 动画层：`src/components/motion/` — PageTransition（路由入场）、Reveal/Stagger（错落/滚动揭示）、ThemeSwitcher（日/月/对比滑动控件）。
4. 外壳现代化：AppShell（玻璃侧栏 + 路由动画 + 点阵底纹）、TopBar（玻璃 sticky + 主题切换器）、SideNav（品牌头 + 渐变激活态 + 图标弹入 + 未读脉冲）、StatusBar 主题化。
5. 微交互：Button 加按压缩放/悬浮阴影；Card 用 `.card-interactive` 悬浮抬升 + 高对比描边；Tabs 激活态修正深色对比。
6. 深色扫荡：脚本把 24 个组件/页面里的 `bg-white`/`slate-[0-9]` 全部替换为语义令牌（保留透明度后缀）。
7. 示范页：ClientHome/MasterHome 改为「欢迎条 + 图标芯片统计卡 + 强调条 + 错落入场 + 悬浮抬升」新语言。

**验证**：`./node_modules/.bin/tsc --noEmit` 0 error（确认 `@tauri-apps/api/core` 误报是 npx 拉错 tsc 版本所致）；`vite build` 1607 模块全部转译通过（CSS/Tailwind 编译 OK），仅末段因本机文件代理拦截 `node_modules/@tauri-apps/api/core.js` 超时中断——与代码无关，真实环境正常。

## 小屏 SideNav 抽屉定位坑（第 3 次修复）
- 现象：前两次 `absolute left-0 top-0 h-full`、`fixed inset-y-0` 都与顶栏/状态栏重叠；`fixed top-[4.5rem] bottom-10` 用魔法数字仍错位（顶栏 `flex-wrap` 在小屏更高、状态栏高度不固定）。
- 根因：中栏 `<div className="flex min-h-0 flex-1">` 不是定位上下文，`absolute` 回退到视口初始包含块，导致覆盖两条栏。
- 修复：中栏加 `relative`；抽屉与遮罩改为 `absolute` 锚定中栏（`left-0 top-0 bottom-0` / `inset-0`），精确落在顶栏与状态栏之间，与两栏真实高度解耦；遮罩只调暗内容区、两栏保持可见。设置项用 `mt-auto` 永远在底部可见。
